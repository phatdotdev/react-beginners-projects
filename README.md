## 📖 Overview

This repository contains a collection of mini-projects built with **React** and **TypeScript** (or JavaScript) to demonstrate foundational web development concepts, UI state handling, and interactive user interfaces. Each project focuses on solving a specific problem or mastering a key React pattern.

---

## 🛠 Tech Stack

- **Frontend:** React (Vite / Create React App)
- **Language:** TypeScript / JavaScript (ES6+)
- **Styling:** CSS3 / Tailwind CSS
- **Version Control:** Git & GitHub
